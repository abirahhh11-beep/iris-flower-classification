# Iris Flower Classification using Machine Learning

## Project Overview

This project uses Machine Learning to classify Iris flowers into three species based on their sepal and petal measurements.

## Dataset

* Dataset: Iris.csv
* Original records: 150
* Records used after removing duplicates: 147
* Features: 4
* Target classes: 3

## Algorithm

Logistic Regression

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Project Workflow

1. Load the dataset.
2. Clean and preprocess the data.
3. Analyze the flower measurements.
4. Split the dataset into training and testing sets.
5. Train the Logistic Regression model.
6. Evaluate the model's performance.
7. Predict the Iris flower species.

## Model Performance

* Test Accuracy: 96.67%
* Algorithm: Logistic Regression

## Conclusion

The model successfully classifies Iris flower species using sepal and petal measurements, achieving 96.67% accuracy on the test dataset.
